### Important implementation limits

- `src/server/env.ts` calls `assertLocalDatabase` and `assertLocalHttp` from `scripts/local-safety.mjs`: only named loopback databases and local HTTP auth origins are accepted. `SMTP_HOST` is loopback-only. `src/server/mail.ts` uses `secure:false` and `ignoreTLS:true` for local Mailpit. These are deliberate local safeguards, not a production email implementation. Supplying cloud credentials alone will not work.
- `src/server/db.ts` uses Prisma/PostgreSQL with a pool maximum of five. `compose.yaml` is explicitly local development/test infrastructure. No inspected configuration proves production PostgreSQL, restricted service roles, TLS, pooling/capacity, migration ownership or failover.
- `src/server/images/storage.ts` only implements `.data/vehicle-images/{development,test}` and binds namespaces to local DB targets. The interface is suitable for an adapter, but a bucket, durable hosted volume, ACLs and provider connection have not been implemented/proved.
- Public catalogue reads evaluate up to 500 candidates and 100 enabled policies, with overflow failing closed. Public image delivery repeats eligibility work. No public request rate limit or production load evidence was found in the public handlers. Keep pilot capacity bounded and test it; do not assume internet-facing capacity from local fixtures.
- OFF mode exposes legacy `KILIFI_FLEET` with pending-review wording. `/cars/vitz.jpg` and `/cars/note.jpg` are absent from the inspected public file inventory. This is useful compatibility behavior, but it is not an approved-real-inventory marketplace. An OFF rollback that republishes unreviewed legacy vehicles is **not an acceptable pilot safety rollback**; use an unavailable/empty catalogue or retain only legitimately eligible records.
- `Footer.tsx`, `src/app/about/page.tsx` and `src/app/services/page.tsx` still make broad verified-fleet claims. `/pricing` advertises monthly subscriptions and a host tracking ledger although billing is out of scope and that ledger is not implemented. Preserve URLs where practical, but remove/qualify these claims for the pilot.
- No expiry/reverification scheduler for time-limited rental evidence was found. A dated manual expiry register plus suspension procedure can satisfy a small pilot; automation is not required now.
